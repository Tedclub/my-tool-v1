# 🚀 強勢多頭排列防守導航儀 V2：技術指標與風控空間計算器

V2 的定位是「技術指標＋風控空間計算器」，不是持倉管理系統。系統把兩種容易混淆的概念分開：

1. **今日動態指標**：以最新收盤價與最新波動 R 重新計算，數值每天可以改變。
2. **固定基準試算**：使用者自行指定基準價格與基準 R，用來計算固定防守、+1R、+2R；這組數值不會因為今日收盤價改變而自己往前移。

這樣可以避免舊版中「目標價與防守價一直跳動，看不清楚哪一組才是固定交易基準」的問題。

---

## 一、 三個狀態燈

### 📈 趨勢
多頭排列的定義為：

```
最新收盤價 > 短均線 > 長均線
```

預設為：

```
Close > MA5 > MA20
```

這只是本工具的趨勢條件，不代表未來一定上漲。

### 🎯 2R
只有在「固定基準試算」填入基準價格與基準 R 後，系統才會判斷目前價格相對基準位於幾 R。

因此 V2 不再使用「今日收盤價 >= 用今日收盤價重新算出的 2R 目標」這種無法成立的邏輯。

### 📏 乖離
顯示最新收盤價相對短均線的乖離率。

預設高乖離提示門檻為：

```
短均線正乖離 >= 8%
```

只有向上的正乖離達到 8% 才視為高乖離；負乖離會正常顯示，但不套用這個高乖離分類。

---

## 二、 今日動態指標

今日動態指標每次查詢都會使用最新交易日資料重新計算。

### 1. True Range（TR）

```
TR = MAX(
  High - Low,
  ABS(High - Previous Close),
  ABS(Low - Previous Close)
)
```

### 2. 平均 True Range（R）

V2 的 R 定義為「最近 N 日 TR 的簡單平均」：

```
R = 最近 N 日 TR 總和 / N
```

預設 N = 5。

> 注意：這不是 Wilder 平滑公式的標準 ATR。V2 刻意使用「平均 True Range」這個名稱，以避免混淆。

### 3. 今日風控距離

```
今日風控距離 = 風控乘數 N × R
```

預設風控乘數 N = 2。

### 4. 今日參考防守價

```
今日參考防守價 = 最新收盤價 - (N × R)
```

它代表「如果只以今天市場波動狀況做一次新的風險空間估算，下方參考位置在哪裡」。

它不是既有部位的固定停損價。

如果理論值小於 0，V2 會以 0 元顯示，並提示這個風控距離在實務上已失去意義。

### 5. 今日 2R 參考上緣

```
今日 2R 參考上緣 = 最新收盤價 + 2 × (N × R)
```

它是「以今天最新收盤價重新量出的上方 2R 空間」，不是固定波段目標，因此每天重新計算是正常現象。

### 6. 今日參考風險 %

```
今日參考風險 % = (N × R) / 最新收盤價 × 100%
```

V2 保留原本的自訂分級：

| 今日參考風險 | 條件顯示 |
|---|---|
| ≤ 4% | 低風險區間 |
| > 4% 且 ≤ 7% | 一般風險區間 |
| > 7% | 風險距離偏高 |
| 未形成多頭排列 | 多頭條件未成立 |

這些門檻是本工具的自訂分類，不是市場通用標準，也不代表勝率保證。

## 三、 固定基準試算

固定基準試算用來回答：

> 如果我把某個價格與某個 R 當作固定起點，那真正不會自己往前跑的防守、+1R、+2R 在哪裡？

需要輸入：

- **基準價格**
- **基準 R**
- 使用目前畫面設定的風控乘數 N

### 1. 固定 1R 距離

```
固定 1R 距離 = 基準 R × N
```

### 2. 固定基準防守

```
固定基準防守 = 基準價格 - 固定 1R 距離
```

若理論值小於 0，畫面以 0 元顯示。

### 3. +1R

```
+1R = 基準價格 + 固定 1R 距離
```

### 4. +2R

```
+2R = 基準價格 + 2 × 固定 1R 距離
```

### 5. 目前位於幾 R

若已先查詢股票最新收盤價：

```
目前 R 倍數 = (最新收盤價 - 基準價格) / 固定 1R 距離
```

例如：

- 基準價格：73
- 基準 R：2
- N：2

則：

- 固定 1R 距離 = 4
- 固定基準防守 = 69
- +1R = 77
- +2R = 81

即使之後最新收盤價變成 75、78 或 80，這組 69 / 77 / 81 都不會重新往前移。

> 固定基準只在目前頁面工作階段有效。重新整理或關閉頁面後，需要重新輸入。

---

## 四、 為什麼 V2 要把兩種數值分開？

舊版同時把「以今日收盤重新估算的風險空間」與「一筆交易應該固定下來的 R 基準」混在一起，因此會出現：

- 今天目標 78
- 股價漲到 75 後，重新計算目標變成 83
- 股價再漲，目標又繼續往前移

這不是計算錯誤，而是「重新計算的動態尺規」被誤解成「固定交易目標」。

V2 明確區分：

### 今日動態層
每天可變：

- 最新收盤價
- MA
- TR
- 平均 TR（R）
- 今日風控距離
- 今日參考防守價
- 今日 2R 參考上緣
- 今日參考風險 %
- MA 乖離率

### 固定基準層
由使用者指定後固定：

- 基準價格
- 基準 R
- 固定基準防守
- +1R
- +2R
- 目前相對基準的 R 倍數

---

## 五、 資料日期與資料完整性

V2 會：

- 明確顯示「資料日期：YYYY/MM/DD 收盤」
- 提醒此頁不是即時報價
- 先把 API 日期標準化為 YYYY-MM-DD，再依字串排序
- 檢查歷史資料是否足夠計算長均線
- 遇到無效價格或資料不足時停止計算
- 將錯誤顯示在頁面內，不再用彈出式 alert 打斷操作
- 自動移除股票代碼前後空白與全形空白

---

## 六、 使用方式

1. 輸入股票代碼。
2. 設定 N、短均線/R 週期、長均線。
3. 按「開始技術指標計算」。
4. 先看最新資料日期、趨勢條件、MA 乖離與今日波動風險。
5. 分析結果下方會出現「固定基準試算」。
6. 若要做固定 R 情境試算，輸入基準價格與基準 R。
7. 也可以按「以本次收盤與 R 填入基準」，把本次計算結果當作固定試算起點。

---

## 七、 重要限制

本工具是技術指標與風控空間計算器：

- 不記錄真實持股數量
- 不計算券商實際損益
- 不代表自動交易系統
- 不保證任何技術條件具有特定勝率
- 不預測未來價格
- 「今日動態參考」與「固定基準試算」用途不同，不能混為同一個停損或目標概念
